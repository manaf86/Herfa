# نطاق النسخة الأولى (MVP) — مقدّس

> أي طلب خارج هذه القائمة يُرفض ويُسجَّل في `docs/backlog.md`.
> الوكيل `product-manager` مسؤول عن حراسة هذا الملف.

## داخل النطاق

- [ ] تسجيل موحد (بريد/جوال/Google/Apple) — **حساب واحد، لا سؤال عن الدور**
- [ ] KYC للبائع: طبقتان فقط — هوية، مهارة
- [ ] ملف بائع + خدمة مسعّرة + عرض مخصص
- [ ] محادثة + غرفة طلب + رفع ملفات
- [ ] ضمان (Escrow) عبر **مزوّد دفع مرخّص** — استدعاء فقط
- [ ] عدّاد تنازلي يبدأ **عند اكتمال المتطلبات** لا عند الدفع
- [ ] تسليم + مراجعة ٥ أيام + إشعاران + قبول تلقائي
- [ ] طلب تعديل ضمن حد الباقة
- [ ] تمديد بموافقة الطرفين
- [ ] نافذة حماية ١٤ يوماً بعد القبول (بلاغ احتيال فقط)
- [ ] صندوق حماية البائع (1.5% من كل عمولة)
- [ ] تقييم متبادل يُنشر بعد تقييم الطرفين أو ١٠ أيام
- [ ] غرفة نزاع **بشرية** — يجوز إدارتها بالبريد في البداية.
      المهم الوعد لا الأتمتة.
- [ ] سحب أرباح: تحويل بنكي محلي + Payoneer
- [ ] RTL أصلي
- [ ] لوحة إدارة أساسية + سجل تدقيق (AuditLog)

## خارج النطاق صراحةً (لا تبنِه)

- ❌ ترويج مدفوع
- ❌ اشتراكات
- ❌ تطبيق جوال
- ❌ مسابقات وتحديات
- ❌ متجر أصول رقمية
- ❌ وكلاء ذكاء اصطناعي
- ❌ لوحات كانبان و Gantt  ← **المرحلة الثانية**
- ❌ معالم مالية متعددة داخل الطلب ← **المرحلة الثانية** (المرحلة الأولى: دفعة واحدة)
- ❌ محرك مطابقة ذكي     ← **المرحلة الثانية**
- ❌ الجسر اللغوي         ← **المرحلة الثانية**

## بوابة الخروج
لا ننتقل للمرحلة الثانية قبل:
- 50 طلباً مكتملاً بنجاح موثّق
- معدل نزاعات < 5%
- 20 مشترياً عاد لطلب ثانٍ
