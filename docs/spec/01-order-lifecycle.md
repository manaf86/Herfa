# مواصفة: دورة حياة الطلب

## الحالات (Order.status)

| الحالة | المعنى | من ينتظر؟ |
|---|---|---|
| `PENDING_PAYMENT` | أُنشئ الطلب، لم يُدفع | المشتري |
| `AWAITING_REQUIREMENTS` | المال في الخزنة. **العدّاد لم يبدأ.** | المشتري |
| `IN_PROGRESS` | العدّاد يعمل | البائع |
| `DELIVERED` | سُلّم، بانتظار المراجعة | المشتري |
| `REVISION_REQUESTED` | طلب تعديل ضمن المسموح | البائع |
| `DISPUTED` | نزاع مفتوح | المنصة |
| `ACCEPTED` | قُبل. المال في `PENDING_CLEARANCE` | النظام |
| `COMPLETED` | مرّت ٥ أيام. قابل للسحب | — |
| `CANCELLED` | ملغى، استرداد كامل أو جزئي | — |

## القواعد الحاكمة

### ١. العدّاد
- يبدأ عند `AWAITING_REQUIREMENTS → IN_PROGRESS`، أي **عند اكتمال المتطلبات**،
  لا عند الدفع.
- إن لم يرسل المشتري المتطلبات خلال ٧ أيام → تذكير، ثم إلغاء تلقائي
  واسترداد كامل. **البائع لا يُعاقَب.**
- **التمديد يتطلب موافقة الطرفين** ويُسجَّل في `OrderEvent`.
  التمديد المتفق عليه لا يُحتسب تأخيراً ضد البائع.

### ٢. القبول التلقائي (Auto-accept)
- المشتري لديه **٥ أيام** بعد التسليم.
- إشعاران إلزاميان: بعد ٤٨ ساعة، وقبل ١٢ ساعة من انتهاء المهلة.
- عند الانتهاء: `DELIVERED → ACCEPTED` تلقائياً.
- ⚠ القبول التلقائي **لا يفتح السحب فوراً** — انظر القاعدة ٣.

### ٣. مسار المال
```
الشراء → ESCROW_HOLD
القبول → PENDING_CLEARANCE  (٥ أيام)
انقضاء المدة → AVAILABLE  (قابل للسحب)
```
- **نافذة حماية ١٤ يوماً** بعد `ACCEPTED`: يستطيع المشتري فتح
  **بلاغ احتيال فقط** — لا نزاع جودة. الجودة تُحسم قبل القبول.
- بعد ١٤ يوماً: العلاقة خارج نطاق ضمان المنصة. **يُكتب صراحةً في الشروط.**

### ٤. الاسترداد البنكي (Chargeback)
- يصل بعد ٦٠–١٢٠ يوماً عبر شبكة البطاقة. **شروطنا لا تُلزم بنك المشتري.**
- إن كان البائع سلّم عملاً مقبولاً وموثّقاً:
  **صندوق حماية البائع** يعوّضه. لا نسترد من رصيده.
- الصندوق يُموَّل من نسبة ثابتة من كل عمولة (ابدأ بـ 1.5% وعايره بالبيانات).

### ٥. التعديلات
- عدد التعديلات المجانية من الباقة. تجاوزها = عرض مدفوع أو نزاع.
- طلب تعديل خارج نطاق الوصف الأصلي = **ليس تعديلاً**، بل طلب جديد.
  الوكيل `security-auditor` لا يعنيه هذا، لكن `product-manager` يحرسه.

### ٦. الإلغاء
| الحالة | النتيجة |
|---|---|
| قبل بدء العدّاد | استرداد كامل، بلا أثر على أي طرف |
| البائع تجاوز المهلة دون تسليم | استرداد كامل + أثر على مؤشر البائع |
| اتفاق الطرفين | استرداد كامل، بلا أثر على أي طرف |
| رفض المشتري بلا سبب بعد تسليم مطابق | تحكيم — قد يُصرف للبائع كاملاً |

### ٧. التقييم
- يُفتح للطرفين بعد `ACCEPTED` أو بعد قرار نزاع.
- **يُنشر بعد أن يقيّم الطرفان، أو بعد ١٠ أيام** — أيهما أسبق.
  (يمنع التقييم الانتقامي.)
- تقييم مثبَّت بالمعاملة فقط. لا تقييم بلا طلب.
