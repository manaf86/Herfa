# تدفّق منصة حِرفة

## الأدوار
حساب واحد، دوران قابلان للتبديل من الشريط العلوي: مشترٍ / محترف.

## رحلة المحترف (البائع)
1. ينشئ خدمة مسعّرة (باقات) تظهر في لوحته المربّعة.
2. يستقبل طلباً → يتفقان في شات الموقع → يبدأ التنفيذ.
3. العدّاد يبدأ عند اكتمال المتطلبات (لا عند الدفع).
4. ينفّذ عبر مساحة العمل (كانبان + معالم مالية).
5. عند اعتماد كل معلم تُفرَج دفعته من الخزنة تلقائياً.
6. بعد الاكتمال يأخذ تقييماً وتُصرف أرباحه (بعد فترة تصفية).

## رحلة المشتري
1. يتصفّح المهارات أو يطرح مشروعاً.
2. يختار محترفاً ويدفع → المال يُحجز في الخزنة.
3. يتابع التقدّم في مساحة العمل، يعلّق ويطلب تعديلات.
4. يعتمد المعالم → يُفرج عن الدفعات.
5. يقيّم عند الاكتمال.

## المبدأ الحاكم للداشبورد
لوحة القيادة = نمو وشفافية، لا عقاب. كل مؤشر يُظهر سببه وكيف يتحسّن.
مساحة العمل = ميزتنا الحصرية: مهام + معالم مالية مربوطة بالخزنة.
